# Rare Dive

A browser-based rare-answer game with timed prompts and an underwater depth score.

## Play

- [Play Rare Dive](https://fitnessforjesus.github.io/rare-dive/)
- [Open the game file](https://fitnessforjesus.github.io/rare-dive/rare-dive.html)

## Run locally

Open `rare-dive.html` in any modern browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/rare-dive.html`.
